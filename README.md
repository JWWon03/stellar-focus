# Stellar Focus — 우주 집중 타이머

집중/공부 세션을 완주하면 가챠 토큰을 얻고, 뽑은 천체로 나만의 항성계를 만들어 가는 타이머입니다.

## 실행

`index.html`을 더블클릭하면 끝입니다. 외부 라이브러리·폰트·서버가 전혀 필요 없고, 오프라인에서 동작합니다.
저장은 브라우저 `localStorage`를 씁니다 (같은 브라우저에서만 유지되고, 시크릿 모드나 브라우저 데이터 삭제 시 사라집니다).

## 규칙 요약

**타이머**
- 카운트다운 / 포모도로를 체크박스로 전환 (진행 중에는 잠김)
- 설정한 집중 시간 = 항성계가 **한 바퀴** 공전하는 시간
- 가장 바깥 궤도의 행성이 제자리로 돌아오면 세션 완료. 안쪽 행성은 케플러 제3법칙(`T ∝ r^1.5`)에 따라 더 빠르게 돔
- 집중 중에는 모든 천체가 **검은 구체**, 중심별도 어둡게 꺼짐 → 완료 시 중심에서 빛이 퍼지며 리빌
- 완료 보상: 토큰 1개. 포모도로는 `긴 휴식 주기`(기본 4)회차마다 보너스 포함 2개
- 중도 초기화 시 토큰 없음

**가챠**
- 배너 3종: 항성(동반성) / 행성 / 위성
- 확률 ★5 4% · ★4 22% · ★3 74%
- **중복 없음** — 미보유 천체 중에서만 추첨. 해당 등급이 소진되면 상위 등급부터 대체
- 천장: 10회 안에 ★4 이상 확정, 30회 안에 ★5 확정 (배너별로 따로 누적)
- 뽑은 천체는 곧바로 배치되지 않고 **보관함/도감**에 들어감

**항성계**
- 중심별: 최초 1회 이름 + 색(스펙트럼형 12색) 지정, 이후 설정에서 수정 가능
- 행성 최대 **7기** (궤도 슬롯 1~7, 안쪽 → 바깥쪽)
- 위성은 **행성 1기당 최대 2기**
- 동반성 최대 2기 (중심별 안쪽 궤도를 공전 — 실제 쌍성 역학은 계산하지 않고 시각 연출만)

**수집 총량**: 항성 12 · 행성 18 · 위성 16 = 46종

## 화면 배치

| 위치 | 내용 |
|---|---|
| 좌상단 | 오늘 날짜 / 시각 / 오늘 누적 집중 시간 |
| 우상단 | 보유 토큰 + 가챠 배너 버튼 |
| 좌하단 | 타이머 위젯 (`—` 버튼으로 접기, `♪`로 완료음 토글) |
| 우하단 | 항성계 설정 버튼 |

## 나중에 모바일 앱으로 만들기

지금 파일은 그대로 모바일 앱으로 감쌀 수 있게 짜여 있습니다 — 반응형 레이아웃, 터치 대응,
safe-area 인셋 처리, 외부 네트워크 요청 0개, 절대 시각(타임스탬프) 기반 타이머라
앱이 백그라운드로 내려갔다 와도 남은 시간이 어긋나지 않습니다.

가장 손이 적게 가는 경로는 Capacitor입니다.

```bash
npm create vite@latest stellar-focus-app -- --template vanilla
```

만든 프로젝트의 `index.html`을 이 파일로 교체한 뒤:

```bash
npm i @capacitor/core @capacitor/cli && npx cap init
```

```bash
npm run build && npx cap add android && npx cap sync && npx cap open android
```

Android Studio에서 APK를 뽑으면 됩니다. iOS는 `npx cap add ios` + Xcode(맥 필요).

설치까지는 필요 없고 홈 화면에만 두고 싶다면, 파일을 아무 정적 호스팅(GitHub Pages 등)에
올리고 모바일 브라우저의 "홈 화면에 추가"를 쓰는 방법이 더 간단합니다.

## 초기화

항성계 설정 → 좌하단 `전체 초기화`. 중심별·보관함·토큰·기록이 모두 지워지고 처음부터 다시 시작합니다.
