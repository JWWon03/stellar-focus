# Stellar Focus — 우주 집중 타이머

집중/공부 세션을 완주해 미보유 실존 천체를 모으고, 그것을 궤도에 배치해 나만의 항성계를 키우는 타이머입니다.

## 실행

`index.html`을 더블클릭하면 끝입니다. 외부 라이브러리·폰트·서버가 전혀 필요 없고, 오프라인에서 동작합니다.
저장은 브라우저 `localStorage`를 씁니다. 계정을 만들면 클라우드에 동기화되어 다른 기기에서도 같은 항성계를 이어서 키울 수 있습니다.

바로 써보기 → **https://jwwon03.github.io/stellar-focus/**

## 규칙 요약

**타이머**
- 카운트다운 / 포모도로를 탭으로 전환 (진행 중에는 메뉴가 잠김 — 타이머 자체는 일시정지·종료 가능)
- 설정한 집중 시간 = 항성계가 **한 바퀴** 공전하는 시간
- 가장 바깥 궤도의 행성이 제자리로 돌아오면 세션 완료. 안쪽 행성은 케플러 제3법칙(`T ∝ r^1.5`)에 따라 더 빠르게 돔
- 집중 중에는 행성·위성이 **어두워집니다**(밝기 0.62) → 완료 시 중심에서 빛이 퍼지며 완전히 밝아짐.
  **중심별은 예외로 항상 밝습니다**
- 최소 집중 시간 10분

**완주 보상 — 집중 연출이 곧 수집 방향**

고른 집중 연출이 무엇을 얻을지 정합니다. 짝은 **실제로 그 방법이 밝혀내는 대상**에 맞췄습니다.

| 집중 연출 | 얻는 것 | 왜 |
|---|---|---|
| 엄폐(식) 관측 | 행성 | 실제로 외계행성을 찾는 바로 그 방법 |
| 벨트 탐사 | 왜소행성 | 카이퍼 벨트 탐사가 잡아내는 것 |
| 탐사선 항해 | 위성 | 보이저·카시니가 위성을 가장 많이 밝혀냄 |
| 혜성 근일점 | 혜성 | 근일점 통과를 지켜보는 것이 새 혜성을 확정하는 일 |
| 분광 관측 | 항성 | 실제로 별을 분류하는 바로 그 방법 |
| 없음 | 남은 종류에서 무작위 | 연출을 껐다고 빈손으로 보내지 않음 |

- **중복이 나오지 않습니다** — 미보유 천체 중에서만 뽑습니다. 그 종류를 다 모으면 아직 남은 다른 종류로 넘어갑니다
- 포모도로는 `긴 휴식 주기`(기본 4)회차마다 **두 종**
- **112종을 모두 모으면** 이후 완주에서는 천체 대신 완주 기록만 추가됩니다
- 완주하면 **발견 연출**이 뜹니다. 연출마다 결말이 다릅니다 — 벨트 탐사는 주변 수치 표시를 감추고 표적 브래킷을 확대합니다. 브래킷과 배경이 함께 검정으로 페이드된 뒤 천체 정보로 이어지며,
  엄폐는 광도 곡선에서 반지름이 나오고, 혜성은 관측점 셋에서 궤도가 풀립니다. 설정에서 끌 수 있습니다
- 중심별을 만들면 천체 하나를 바로 줍니다

**항성계**
- 중심별: 최초 1회 이름 + 색(스펙트럼형 12색) 지정, 이후 설정에서 수정 가능
- 행성 최대 **7기** (궤도 슬롯 1~7, 안쪽 → 바깥쪽). 왜소행성도 같은 슬롯을 씁니다
- 위성은 **행성 1기당 최대 2기**
- 동반성 최대 2기 — 실제 쌍성처럼 **공통 질량중심**을 계산하고, 둘이면 계층적 삼중성으로 풉니다
- 혜성 **1기**. 궤도가 아주 길쭉해 중심별에 가까울 때만 꼬리가 보입니다
- 배치된 가장 바깥 행성이 **기준 궤도**가 되어 카이퍼 벨트와 혜성 궤도까지 함께 밀려납니다

**수집 총량**: 항성 29 · 행성 25 · 왜소행성 12 · 위성 28 · 혜성 18 = **112종**

전부 실존 천체이고, 제원표의 지름·질량·온도·거리는 실측값입니다.
태양계 천체 13종은 실제 관측 텍스처를 쓰고, 나머지는 관측된 조성에 근거해 코드로 표면을 생성합니다.

**그 밖에**
- **집중 기록** — 좌상단 날짜·시각을 누르면 하루 24시간 띠와 달력을 봅니다. 달력 위쪽의 월·연도 목록에서 원하는 시점으로 바로 이동할 수 있습니다
- **촬영 모드** — HUD를 숨기고 비율을 골라 항성계를 사진으로 저장합니다
- **PWA** — 홈 화면에 추가하면 전체화면으로 뜨고 오프라인에서 동작합니다

## 화면 배치

| 위치 | 내용 |
|---|---|
| 좌상단 | 날짜 / 시각 / 오늘 누적 집중 시간 + 계정 버튼 (**누르면 집중 기록**) |
| 우상단 | 알림 종 + 메뉴 넷 (항성계 · 도감 · 촬영 · 설정) |
| 좌하단 | 타이머 위젯 (모드는 탭, `—`로 접기, 스피커로 완료음 토글) |
| 우하단 | Face-on · Edge-on · 확대축소 |

## 나중에 모바일 앱으로 만들기

지금 파일은 그대로 모바일 앱으로 감쌀 수 있게 짜여 있습니다 — 반응형 레이아웃, 터치 대응,
safe-area 인셋 처리, 외부 네트워크 요청 0개, 절대 시각(타임스탬프) 기반 타이머라
앱이 백그라운드로 내려갔다 와도 남은 시간이 어긋나지 않습니다.

**`mobile/` 폴더에 Capacitor 래퍼가 준비돼 있습니다.** 빌드 방법은 [mobile/README.md](mobile/README.md)를 보세요.

앱으로 감싸는 실익은 **알림**입니다. 웹(PWA)은 앱을 완전히 종료하면 예약 알림을 띄울 수
없지만, 앱은 안드로이드 OS에 알림을 예약하므로 종료해도 제때 옵니다. 나머지 기능은
같은 `index.html`을 쓰므로 완전히 동일합니다.

```bash
cd mobile && npm install && npm run sync-web && npx cap add android && npm run apk
```

JDK 17 · Node.js · Android Studio(SDK용)가 필요합니다. iOS는 `npx cap add ios` + Xcode(맥 필요).

설치까지 필요 없다면 https://jwwon03.github.io/stellar-focus/ 를 모바일 브라우저로 열고
"홈 화면에 추가"를 쓰면 됩니다. 아이콘이 생기고 전체화면으로 뜹니다.

## 초기화

항성계 설정 → 좌하단 `전체 초기화`. 중심별·보관함·기록이 모두 지워지고 처음부터 다시 시작합니다.
로그인 상태라면 클라우드 저장본도 함께 비워집니다.
